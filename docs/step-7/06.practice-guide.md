# 06. 실습 가이드

이 문서는 단계별 실습 미션과 테스트 시나리오를 통해 Library Assistant Agent를 직접 구현해 볼 수 있는 가이드입니다.

> **리팩토링 업데이트**: 이 실습 가이드는 최신 리팩토링 내용을 반영하여 업데이트되었습니다.
> - FunctionToolCallback.builder() 방식으로 Function 등록
> - 순환 의존성을 피하기 위해 ToolCallback과 ChatClient를 Bean으로 등록하지 않고 AiLibraryAssistantService 안에서 직접 생성
> - @Description 애노테이션 대신 직접 메서드로 구현

### 미션 2-3: BookSearchFunction 구현

**파일**: `ai/function/BookSearchFunction.java`

```java
package net.java21.library.ai.function;

import net.java21.library.ai.function.dto.BookSearchRequest;
import net.java21.library.ai.function.dto.BookSearchResult;
import net.java21.library.core.book.domain.SearchType;
import net.java21.library.core.book.dto.BookSearchResponse;
import net.java21.library.core.book.service.search.BookSearchService;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.data.domain.PageRequest;
import org.springframework.stereotype.Component;

/**
 * 도서 검색 Function (Spring AI 1.1.2 FunctionToolCallback 방식)
 * <p>
 * FunctionToolCallback.builder()에서 메서드 레퍼런스(bookSearchFunction::searchBooks)로 사용합니다.
 * </p>
 */
@Component
@RequiredArgsConstructor
@Slf4j
public class BookSearchFunction {

    private final BookSearchService bookSearchService;

    public BookSearchResult searchBooks(BookSearchRequest request) {
        log.info("[AI Function] 도서 검색 시작: query={}", request.query());

        try {
            // 1. 내부 DB 검색 실행 (하이브리드 검색)
            var coreRequest = new net.java21.library.core.book.dto.BookSearchRequest(
                request.query(),
                null,
                SearchType.HYBRID,
                null,
                false
            );

            var result = bookSearchService.searchBooks(
                PageRequest.of(0, request.limit()),
                coreRequest
            );

            // 2. 결과 변환
            var bookItems = result.getBooks().getContent().stream()
                .map(this::toBookItem)
                .toList();

            log.info("[AI Function] 검색 완료: {}권", bookItems.size());

            // 3. 결과 반환
            return BookSearchResult.from(bookItems);

        } catch (Exception e) {
            log.error("[AI Function] 검색 실패: query={}", request.query(), e);
            return BookSearchResult.empty();
        }
    }

    private BookSearchResult.BookItem toBookItem(BookSearchResponse book) {
        return BookSearchResult.BookItem.from(
            book.getId(),
            book.getTitle(),
            book.getAuthorName(),
            book.getPublisherName(),
            book.getIsbn(),
            "내부 DB"
        );
    }
}
```

### 미션 2-4: Tool 등록 방식 이해 (AiConfig는 수정하지 않음)

**확인할 파일**: `core/config/AiConfig.java`

FunctionToolCallback과 ChatClient를 AiConfig에 Bean으로 등록하는 방법도 있지만, 이 프로젝트에서는 사용하지 않습니다. AiConfig는 `spring.ai.selected-model`에 따라 @Primary ChatModel을 만드는 설정 클래스이므로, 같은 클래스가 ChatModel과 Function 컴포넌트를 주입받아 ToolCallback·ChatClient Bean까지 만들면 Bean 생성 과정에서 순환 의존성이 생깁니다. 그래서 실제 소스는 Tool과 ChatClient를 `AiLibraryAssistantService` 안에서 요청마다 직접 생성합니다.

이 방식의 장점은 다음과 같습니다.
- 주입받는 `ChatModel`은 AiConfig의 @Primary Bean이므로 Gemini/Ollama 중 무엇을 선택해도 동일한 코드로 동작합니다.
- 모델별 ChatClient Bean 이름을 `@Qualifier`로 지정할 필요가 없습니다.

**체크리스트**:
- [ ] AiConfig에 FunctionToolCallback Bean을 추가하지 않음
- [ ] Bean 등록 대신 서비스 내부 생성 방식을 쓰는 이유(순환 의존성)를 설명할 수 있음

### 미션 2-5: AiLibraryAssistantService 구현

**파일**: `ai/service/AiLibraryAssistantService.java`

> **중요**: ChatModel과 Function 컴포넌트를 주입받고, `ask()` 안에서 FunctionToolCallback과 ChatClient를 직접 생성합니다.

```java
package net.java21.library.ai.service;

import net.java21.library.ai.function.BookSearchFunction;
import net.java21.library.ai.function.dto.BookSearchRequest;
import net.java21.library.ai.function.dto.BookSearchResult;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.model.ChatModel;
import org.springframework.ai.tool.function.FunctionToolCallback;
import org.springframework.stereotype.Service;

/**
 * Library Assistant Agent 메인 서비스
 * <p>
 * 순환 의존성 문제로 FunctionToolCallback을 Bean으로 등록하지 않고,
 * 서비스 내부에서 프로그래밍 방식으로 생성합니다.
 * </p>
 */
@Service
@RequiredArgsConstructor
@Slf4j
public class AiLibraryAssistantService {

    private final ChatModel chatModel;  // AiConfig의 @Primary ChatModel
    private final BookSearchFunction bookSearchFunction;

    /**
     * 사용자 요청을 처리하고 AI 응답을 반환합니다.
     *
     * @param userMessage 사용자 메시지
     * @return AI 응답
     */
    public String ask(String userMessage) {
        log.info("[AI Service] 사용자 요청: {}", userMessage);

        // FunctionToolCallback 프로그래밍 방식 생성 (순환 의존성 방지)
        FunctionToolCallback<BookSearchRequest, BookSearchResult> bookSearchTool =
            FunctionToolCallback.builder("BookSearch", bookSearchFunction::searchBooks)
                .description("도서관 시스템에서 도서를 검색합니다. " +
                            "제목, 저자명으로 검색할 수 있으며, 검색어를 받아 도서 목록을 반환합니다.")
                .inputType(BookSearchRequest.class)
                .build();

        // ChatClient 생성 (Function Tool 등록)
        ChatClient chatClient = ChatClient.builder(chatModel)
            .defaultToolCallbacks(bookSearchTool)
            .build();

        // System Prompt
        String systemPrompt = """
            당신은 도서관 도우미 AI입니다.

            **중요: 반드시 한국어로만 답변하세요.**

            사용자의 요청을 처리할 때:
            1. 필요한 도구(함수)를 호출하여 정보를 수집하세요
            2. 도구 호출 결과를 받으면 반드시 자연스러운 한국어로 답변하세요
            3. 검색 결과를 친절하게 설명하세요
            """;

        String response = chatClient.prompt()
            .system(systemPrompt)
            .user(userMessage)
            .call()
            .content();

        log.info("[AI Service] AI 응답 생성 완료");
        return response;
    }
}
```

**설명**:
1. `ChatModel`: AiConfig가 `spring.ai.selected-model`에 따라 지정한 @Primary Bean이 주입되므로 `@Qualifier`가 필요 없음
2. `FunctionToolCallback.builder()`: `bookSearchFunction::searchBooks` 메서드 레퍼런스로 Tool 생성
3. `ChatClient.builder(chatModel).defaultToolCallbacks(...)`: 요청마다 Tool이 등록된 ChatClient 생성
4. `systemPrompt`: AI가 한국어로 답변하도록 지시

### 미션 2-6: LibraryTelegramBot 수정 (Step 7)

**기존 파일**: `external/telegram/bot/LibraryTelegramBot.java`

**수정 내용**: AI 서비스를 주입하고, 일반 텍스트 메시지와 `/ai` 명령을 `handleAiAgentSearch()`로 위임

실제 소스의 LibraryTelegramBot은 `AiLibraryAssistantService`와 `AiOrchestrationService`를 모두 생성자로 주입받고, `handleAiAgentSearch()`에서는 `AiOrchestrationService`(05 문서의 Tool 기반 오케스트레이션)를 호출합니다. 이 실습에서 만든 Function을 확인하려면 호출 대상을 `aiLibraryAssistantService.ask()`로 바꿔서 테스트합니다.

```java
// 1. 의존성 주입 (생성자 주입)
private final AiLibraryAssistantService aiLibraryAssistantService; // Step 7 단일 Agent
private final AiOrchestrationService aiOrchestrationService;       // Step 7 Tool 기반 오케스트레이션

// 2. onUpdateReceived 메서드 수정
if (update.hasMessage() && update.getMessage().hasText()) {
    String messageText = update.getMessage().getText();
    Long chatId = update.getMessage().getChatId();

    log.info("[Telegram] Received message from chatId {}: {}", chatId, messageText);

    if (messageText.startsWith("/")) {
        handleCommand(update, messageText);  // "/ai <메시지>"도 handleAiAgentSearch()로 위임
    } else {
        // 일반 텍스트는 AI Agent에게 위임 (Step 7)
        handleAiAgentSearch(update, messageText);
    }
}

// 3. AI Agent 검색 처리 메서드 추가
private void handleAiAgentSearch(Update update, String keyword) {
    Long chatId = update.getMessage().getChatId();

    try {
        // 1. 최근 검색어 저장 (피드백용)
        callbackQueryHandler.setRecentQuery(chatId, keyword);

        // 2. AI 호출 (실제 소스: aiOrchestrationService.ask)
        //    이 실습의 Function을 테스트할 때는 aiLibraryAssistantService.ask(keyword)로 변경
        String aiResponse = aiOrchestrationService.ask(keyword);

        // 3. Telegram으로 응답 전송
        sendSimpleMessage(chatId, aiResponse);
    } catch (Exception e) {
        log.error("[Telegram] AI Agent search failed for: {}, chatId: {}", keyword, chatId, e);
        sendSimpleMessage(chatId, "검색 중 오류가 발생했습니다. 다시 시도해주세요.");
    }
}
```

**체크리스트**:
- [ ] LibraryTelegramBot에 AiLibraryAssistantService와 AiOrchestrationService가 주입됨
- [ ] handleAiAgentSearch 메서드 구현됨
- [ ] 실습 테스트 시 호출 대상을 `aiLibraryAssistantService.ask()`로 바꿈
- [ ] AI Agent 응답을 Telegram으로 전송

### 미션 3-2: ReviewFunction 구현

**파일**: `ai/function/ReviewFunction.java`

> **중요**: 리팩토링 후에는 @Description 애노테이션 대신 직접 메서드로 구현합니다.

```java
package net.java21.library.ai.function;

import net.java21.library.ai.function.dto.ReviewResult;
import net.java21.library.core.review.dto.ReviewResponse;
import net.java21.library.core.review.service.ReviewService;
import net.java21.library.core.book.service.search.BookSearchService;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.data.domain.PageRequest;
import org.springframework.stereotype.Component;

import java.util.List;

/**
 * 리뷰 조회 Function (Spring AI 1.1.2 FunctionToolCallback 방식)
 * <p>
 * AI Agent가 도서의 리뷰를 조회할 때 호출하는 함수입니다.
 * 도서 ID를 받아 리뷰 요약, 평점, 주요 리뷰를 반환합니다.
 * </p>
 */
@Component
@RequiredArgsConstructor
@Slf4j
public class ReviewFunction {

    private final ReviewService reviewService;
    private final BookSearchService bookSearchService;

    private static final int REVIEW_LIMIT = 5;

    /**
     * 리뷰 조회 실행 메서드 (외부에서 호출)
     * <p>
     * FunctionToolCallback.builder()에서 메서드 레퍼런스로 사용합니다.
     * </p>
     */
    public ReviewResult getReviews(Long bookId) {
        log.info("[AI Function] 리뷰 조회 시작: bookId={}", bookId);

        try {
            // 1. 리뷰 조회 (상위 N개)
            var reviews = reviewService.getReviews(
                bookId,
                PageRequest.of(0, REVIEW_LIMIT)
            );

            // 2. 리뷰 요약 조회
            String summary = bookSearchService.getReviewSummary(bookId);

            // 3. 평균 평점 계산
            double avgRating = reviews.getContent().stream()
                .mapToInt(ReviewResponse::rating)
                .average()
                .orElse(0.0);

            // 4. 결과 변환
            List<ReviewResult.ReviewItem> reviewItems = reviews.getContent().stream()
                .map(review -> ReviewResult.ReviewItem.of(
                    review.content(),
                    review.rating()
                ))
                .toList();

            log.info("[AI Function] 리뷰 조회 완료: bookId={}, reviewCount={}",
                bookId, reviewItems.size());

            // 5. 결과 반환
            return ReviewResult.of(
                bookId,
                summary,
                avgRating,
                (int) reviews.getTotalElements(),
                reviewItems
            );

        } catch (Exception e) {
            log.error("[AI Function] 리뷰 조회 실패: bookId={}", bookId, e);
            return ReviewResult.empty(bookId);
        }
    }
}
```

**설명**:
1. `@Description` 애노테이션 사용하지 않음
2. 직접 `getReviews()` 메서드로 구현
3. `ReviewResult.of()`, `empty()` 정적 팩토리 메서드 사용

### 미션 4-3: LoanCheckFunction 구현

**파일**: `ai/function/LoanCheckFunction.java`

> **중요**: 리팩토링 후에는 @Description 애노테이션 대신 직접 메서드로 구현합니다.

```java
package net.java21.library.ai.function;

import net.java21.library.ai.function.dto.LoanCheckRequest;
import net.java21.library.ai.function.dto.LoanCheckResult;
import net.java21.library.external.opennaru.client.LibraryInfoNaruApiClient;
import net.java21.library.external.opennaru.dto.LoanItemInfo;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;

import java.util.List;
import java.util.stream.Collectors;

/**
 * 대출 가능 여부 조회 Function (Spring AI 1.1.2 FunctionToolCallback 방식)
 * <p>
 * AI Agent가 도서의 대출 가능 여부를 조회할 때 호출하는 함수입니다.
 * ISBN을 받아 전국 도서관의 대출 가능 현황을 반환합니다.
 * </p>
 */
@Component
@RequiredArgsConstructor
@Slf4j
public class LoanCheckFunction {

    private final LibraryInfoNaruApiClient libraryInfoNaruApiClient;

    /**
     * 대출 가능 확인 실행 메서드 (외부에서 호출)
     * <p>
     * FunctionToolCallback.builder()에서 메서드 레퍼런스로 사용합니다.
     * </p>
     */
    public LoanCheckResult checkLoanAvailability(LoanCheckRequest request) {
        log.info("[AI Function] 대출 가능 여부 조회 시작: isbn={}", request.isbn());

        try {
            // 1. 도서관정보나루 API 호출
            List<LoanItemInfo> loanItems = libraryInfoNaruApiClient.searchLoanItemsByIsbn(
                request.isbn()
            );

            if (loanItems.isEmpty()) {
                log.info("[AI Function] 대출 가능 도서관 없음: isbn={}", request.isbn());
                return LoanCheckResult.empty(request.isbn());
            }

            // 2. 지역 필터링 (선택 사항)
            List<LoanItemInfo> filteredItems = filterByRegion(loanItems, request.region());

            // 3. 상위 N개 추출
            List<LoanItemInfo> topItems = filteredItems.stream()
                .limit(request.limit())
                .toList();

            // 4. 결과 변환
            List<LoanCheckResult.LibraryInfo> libraries = topItems.stream()
                .map(this::toLibraryInfo)
                .toList();

            log.info("[AI Function] 대출 가능 도서관 조회 완료: isbn={}, count={}",
                request.isbn(), libraries.size());

            return LoanCheckResult.of(
                request.isbn(),
                loanItems.size(),
                libraries
            );

        } catch (Exception e) {
            log.error("[AI Function] 대출 가능 여부 조회 실패: isbn={}", request.isbn(), e);
            return LoanCheckResult.empty(request.isbn());
        }
    }

    /**
     * 지역 기반 필터링
     */
    private List<LoanItemInfo> filterByRegion(List<LoanItemInfo> loanItems, String region) {
        if (region == null || region.isBlank()) {
            return loanItems;
        }
        return loanItems.stream()
            .filter(item -> item.location() != null && item.location().contains(region))
            .collect(Collectors.toList());
    }

    /**
     * LoanItemInfo를 LibraryInfo로 변환
     */
    private LoanCheckResult.LibraryInfo toLibraryInfo(LoanItemInfo item) {
        boolean loanAvailable = "Y".equalsIgnoreCase(item.loanAvailable());

        return LoanCheckResult.LibraryInfo.of(
            item.libraryName(),
            item.location(),
            null, // 거리 정보 (현재 미지원)
            "",   // 전화번호 (현재 미지원)
            loanAvailable,
            ""    // 운영 시간 (현재 미지원)
        );
    }
}
```

**설명**:
1. `@Description` 애노테이션 사용하지 않음
2. 직접 `checkLoanAvailability()` 메서드로 구현
3. `LoanCheckResult.of()`, `empty()` 정적 팩토리 메서드 사용
4. 지역 필터링 로직 포함

```java
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.model.ChatModel;
import org.springframework.ai.tool.function.FunctionToolCallback;
import org.springframework.stereotype.Service;

@Service
@RequiredArgsConstructor
@Slf4j
public class AiLibraryAssistantService {

    private final ChatModel chatModel;
    private final BookSearchFunction bookSearchFunction;
    private final ReviewFunction reviewFunction;
    private final LoanCheckFunction loanCheckFunction;  // 추가

    public String ask(String userMessage) {
        log.info("[AI Service] 사용자 요청: {}", userMessage);

        // FunctionToolCallback 프로그래밍 방식 생성 (순환 의존성 방지)
        FunctionToolCallback<BookSearchRequest, BookSearchResult> bookSearchTool =
            FunctionToolCallback.builder("BookSearch", bookSearchFunction::searchBooks)
                .description("도서관 시스템에서 도서를 검색합니다. " +
                            "제목, 저자명으로 검색할 수 있으며, 검색어를 받아 도서 목록을 반환합니다.")
                .inputType(BookSearchRequest.class)
                .build();

        FunctionToolCallback<Long, ReviewResult> reviewTool =
            FunctionToolCallback.builder("GetReviews", reviewFunction::getReviews)
                .description("도서의 리뷰 목록을 조회합니다. " +
                            "도서 ID를 받아 리뷰 요약, 평점, 주요 리뷰를 제공합니다.")
                .inputType(Long.class)
                .build();

        FunctionToolCallback<LoanCheckRequest, LoanCheckResult> loanCheckTool =
            FunctionToolCallback.builder("CheckLoanAvailability", loanCheckFunction::checkLoanAvailability)
                .description("도서의 대출 가능 여부를 조회합니다. " +
                            "ISBN을 받아 전국 도서관의 대출 가능 현황을 제공합니다. " +
                            "지역, 위도, 경도를 제공하면 해당 지역의 가까운 도서관을 우선으로 보여줍니다.")
                .inputType(LoanCheckRequest.class)
                .build();

        // ChatClient 생성 (3개 Function Tool 등록)
        ChatClient chatClient = ChatClient.builder(chatModel)
            .defaultToolCallbacks(bookSearchTool, reviewTool, loanCheckTool)
            .build();

        String systemPrompt = """
            당신은 도서관 도우미 AI입니다.

            **중요: 반드시 한국어로만 답변하세요.**

            사용자의 요청을 처리할 때:
            1. 필요한 도구(함수)를 호출하여 정보를 수집하세요
            2. 도구 호출 결과를 받으면 반드시 자연스러운 한국어로 답변하세요
            3. 검색 결과, 리뷰, 대출 가능 정보를 종합해서 친절하게 설명하세요
            """;

        String response = chatClient.prompt()
            .system(systemPrompt)
            .user(userMessage)
            .call()
            .content();

        log.info("[AI Service] AI 응답 생성 완료");
        return response;
    }
}
```

```
└── ask()
```

> **참고**: 02~03 문서의 예제 로그는 `[Function]` 접두사를 사용하지만, 실제 소스의 Function 클래스는 `[AI Function]` 접두사로 로그를 남깁니다.

---

### 문제 해결

**문제 1**: AI가 함수를 호출하지 않음

**원인**: FunctionToolCallback의 description이 불명확함

**해결**:
```java
// 나쁜 예
FunctionToolCallback.builder("BookSearch", ...)
    .description("책")
    .build();

// 좋은 예
FunctionToolCallback.builder("BookSearch", bookSearchFunction::searchBooks)
    .description("도서관 시스템에서 도서를 검색합니다. " +
                "제목, 저자명으로 검색할 수 있으며, 검색어를 받아 도서 목록을 반환합니다.")
    .inputType(BookSearchRequest.class)
    .build();
```

---

**문제 2**: 외부 API 타임아웃

**원인**: 응답 시간 초과

**해결**: `RestClient.Builder`의 요청 팩토리에서 읽기 타임아웃 증가
```java
ClientHttpRequestFactorySettings.DEFAULTS
    .withReadTimeout(Duration.ofSeconds(30))
```

---

**문제 3**: 함수 호출 순서가 잘못됨

**원인**: AI가 필요한 데이터를 확보하지 못함

**해결**: AiLibraryAssistantService의 systemPrompt에 순서 명시
```java
// AiLibraryAssistantService.java
public String ask(String userMessage) {
    // ... Tool·ChatClient 생성은 미션 4-4와 동일

    String systemPrompt = """
        당신은 도서관 도우미 AI입니다.

        **중요: 반드시 한국어로만 답변하세요.**

        복잡한 요청 처리 순서:
        1. 도서 검색이 필요하면 BookSearch 호출
        2. 리뷰가 필요하면 GetReviews 호출 (bookId 필요)
        3. 대출 가능 여부가 필요하면 CheckLoanAvailability 호출 (ISBN 필요)

        사용자에게 친절하고 상세한 답변을 제공하세요.
        """;

    return chatClient.prompt()
        .system(systemPrompt)
        .user(userMessage)
        .call()
        .content();
}
```
