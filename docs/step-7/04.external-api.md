## 2. 외부 API 연동이란?

### 2.1. 내부 DB vs 외부 API

**내부 DB 검색** (기존):
```
사용자: "자바 책 찾아줘"
   ↓
[내부 DB 조회]
   ↓
"3권을 찾았습니다..."
```

**외부 API 연동** (이 문서):
```
사용자: "내 주변에서 빌릴 수 있는 자바 책 알려줘"
   ↓
[1단계] 내부 DB 검색 → ISBN 확보
   ↓
[2단계] 도서관정보나루 API 호출 → 대출 가능 도서관 조회
   ↓
[3단계] 거리 기반 필터링 → 가까운 도서관 우선
   ↓
"강남도서관(1.2km)에서 대출 가능합니다!"
```

### 2.2. API 연동 시 고려사항

| 항목 | 고려사항 | 해결 방법 |
|-----|---------|----------|
| **응답 시간** | 외부 API는 느릴 수 있음 | 타임아웃 설정, 비동기 처리 |
| **API 장애** | 외부 서비스 다운 시 대응 | Fallback to 캐시 또는 에러 메시지 |
| **중복 제거** | 같은 도서관이 여러 번 나올 수 있음 | 도서관 ID로 그룹화 |
| **데이터 양** | 전국 도서관 데이터가 너무 많음 | 상위 N개만 반환, 거리 필터링 |

### 3.1. LoanCheckRequest DTO

**LoanCheckRequest.java** (`ai/function/dto/`):

```java
package com.nhnacademy.library.ai.function.dto;

import lombok.Builder;

/**
 * 대출 가능 여부 조회 요청
 *
 * @param isbn ISBN (필수)
 * @param region 지역 코드 (선택, 예: "서울", "경기")
 * @param latitude 위도 (선택, 거리 계산용)
 * @param longitude 경도 (선택, 거리 계산용)
 * @param limit 최대 결과 수 (기본값 10)
 */
@Builder
public record LoanCheckRequest(
    String isbn,
    String region,
    Double latitude,
    Double longitude,
    int limit
) {
    public static LoanCheckRequest of(String isbn) {
        return new LoanCheckRequest(isbn, null, null, null, 10);
    }

    public static LoanCheckRequest of(String isbn, String region) {
        return new LoanCheckRequest(isbn, region, null, null, 10);
    }
}
```

### 3.3. LoanCheckFunction 구현

**LoanCheckFunction.java** (`ai/function/`):

```java
package com.nhnacademy.library.ai.function;

import com.nhnacademy.library.ai.function.dto.LoanCheckRequest;
import com.nhnacademy.library.ai.function.dto.LoanCheckResult;
import com.nhnacademy.library.external.opennaru.client.LibraryInfoNaruApiClient;
import com.nhnacademy.library.external.opennaru.dto.LoanAvailabilityResponse;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.context.annotation.Description;
import org.springframework.stereotype.Component;

/**
 * 대출 가능 여부 조회 Function
 *
 * <p>도서관정보나루 API를 연동하여 전국 도서관의 대출 가능 여부를 조회합니다.</p>
 */
@Component
@RequiredArgsConstructor
@Slf4j
public class LoanCheckFunction {

    private final LibraryInfoNaruApiClient libraryInfoNaruApiClient;

    /**
     * 대출 가능 여부 조회 함수
     *
     * @param isbn ISBN
     * @return 대출 가능 도서관 목록
     */
    @Description("도서의 대출 가능 여부를 조회합니다. " +
            "ISBN을 받아 전국 도서관의 대출 가능 현황을 제공합니다. " +
            "지역, 위도, 경도를 제공하면 해당 지역의 가까운 도서관을 우선으로 보여줍니다.")
    public java.util.function.Function<LoanCheckRequest, LoanCheckResult> checkLoanAvailability() {
        return request -> {
            log.info("[Function] 대출 가능 여부 조회 시작: isbn={}", request.isbn());

            try {
                // 1. 도서관정보나루 API 호출
                var availability = libraryInfoNaruApiClient.getLoanAvailability(
                    request.isbn()
                );

                // 2. 지역 필터링 (선택 사항)
                var filteredLibraries = filterByRegion(availability.libraries(), request.region());

                // 3. 거리 기반 정렬 (위도/경도 제공 시)
                if (request.latitude() != null && request.longitude() != null) {
                    filteredLibraries = sortByDistance(
                        filteredLibraries,
                        request.latitude(),
                        request.longitude()
                    );
                }

                // 4. 상위 N개 추출
                var topLibraries = filteredLibraries.stream()
                    .limit(request.limit())
                    .toList();

                // 5. 결과 변환
                var libraryInfos = topLibraries.stream()
                    .map(this::toLibraryInfo)
                    .toList();

                log.info("[Function] 대출 가능 도서관 조회 완료: isbn={}, count={}",
                    request.isbn(), libraryInfos.size());

                return LoanCheckResult.builder()
                    .isbn(request.isbn())
                    .totalLibraries((int) availability.libraries().size())
                    .libraries(libraryInfos)
                    .build();

            } catch (Exception e) {
                log.error("[Function] 대출 가능 여부 조회 실패: isbn={}", request.isbn(), e);
                // 실패 시 빈 결과 반환
                return LoanCheckResult.builder()
                    .isbn(request.isbn())
                    .totalLibraries(0)
                    .libraries(java.util.List.of())
                    .build();
            }
        };
    }

    /**
     * 지역 기반 필터링
     */
    private List<LoanAvailabilityResponse.Library> filterByRegion(
        List<LoanAvailabilityResponse.Library> libraries,
        String region
    ) {
        if (region == null || region.isBlank()) {
            return libraries;
        }
        return libraries.stream()
            .filter(lib -> lib.address().contains(region))
            .toList();
    }

    /**
     * 거리 기반 정렬 (하버사인 공식)
     */
    private List<LoanAvailabilityResponse.Library> sortByDistance(
        List<LoanAvailabilityResponse.Library> libraries,
        double latitude,
        double longitude
    ) {
        return libraries.stream()
            .sorted((a, b) -> {
                double distA = calculateDistance(
                    latitude, longitude,
                    a.latitude(), a.longitude()
                );
                double distB = calculateDistance(
                    latitude, longitude,
                    b.latitude(), b.longitude()
                );
                return Double.compare(distA, distB);
            })
            .toList();
    }

    /**
     * 두 지점 간의 거리 계산 (km)
     */
    private double calculateDistance(double lat1, double lon1, double lat2, double lon2) {
        final int R = 6371; // 지구 반경 (km)
        double latDistance = Math.toRadians(lat2 - lat1);
        double lonDistance = Math.toRadians(lon2 - lon1);
        double a = Math.sin(latDistance / 2) * Math.sin(latDistance / 2)
            + Math.cos(Math.toRadians(lat1)) * Math.cos(Math.toRadians(lat2))
            * Math.sin(lonDistance / 2) * Math.sin(lonDistance / 2);
        double c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a));
        return R * c;
    }

    /**
     * LoanAvailabilityResponse.Library를 LibraryInfo로 변환
     */
    private LoanCheckResult.LibraryInfo toLibraryInfo(LoanAvailabilityResponse.Library lib) {
        return LoanCheckResult.LibraryInfo.builder()
            .name(lib.name())
            .address(lib.address())
            .distance(lib.distance() != null ? lib.distance() : 0.0)
            .phone(lib.phone())
            .loanAvailable(lib.loanAvailable())
            .operatingHours(lib.operatingHours())
            .build();
    }
}
```

## 4. ChatClient에 3개 Function 등록

### 4.1. AiConfig 최종 수정

**AiConfig.java** (`core/config/AiConfig.java`):

```java
package com.nhnacademy.library.core.config;

import com.nhnacademy.library.ai.function.BookSearchFunction;
import com.nhnacademy.library.ai.function.LoanCheckFunction;
import com.nhnacademy.library.ai.function.ReviewFunction;
import lombok.RequiredArgsConstructor;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.model.ChatModel;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
@RequiredArgsConstructor
public class AiConfig {

    private final ChatModel chatModel;
    private final BookSearchFunction bookSearchFunction;
    private final ReviewFunction reviewFunction;
    private final LoanCheckFunction loanCheckFunction;

    /**
     * Library Assistant Agent용 ChatClient
     *
     * <p>3개의 Function을 등록하여 완전한 도서관 도우미 기능을 제공합니다.</p>
     */
    @Bean
    public ChatClient chatClient() {
        return ChatClient.builder(chatModel)
            // 3개의 함수 등록
            .defaultFunctions(
                bookSearchFunction.searchBooks(),
                reviewFunction.getReviews(),
                loanCheckFunction.checkLoanAvailability()
            )
            .defaultSystemMessage("""
                당신은 도서관 도우미 AI입니다.

                복잡한 요청 처리 순서:
                1. 도서 검색이 필요하면 searchBooks 호출
                2. 리뷰가 필요하면 getReviews 호출 (bookId 필요)
                3. 대출 가능 여부가 필요하면 checkLoanAvailability 호출 (ISBN 필요)

                사용자에게 친절하고 상세한 답변을 제공하세요.
                """)
            .build();
    }
}
```

## 6. 에러 처리 및 Fallback

### 6.1. API 장애 시 Fallback

**시나리오**: 도서관정보나루 API 다운

**구현 방법**:
```java
try {
    var availability = libraryInfoNaruApiClient.getLoanAvailability(isbn);
} catch (Exception e) {
    log.error("[Function] API 호출 실패", e);

    // Fallback: 캐시된 데이터 확인
    var cached = cacheService.get("loan:" + isbn);
    if (cached != null) {
        return cached;
    }

    // 최후의 수단: 에러 메시지 반환
    return LoanCheckResult.builder()
        .isbn(isbn)
        .totalLibraries(0)
        .libraries(java.util.List.of())
        .build();
}
```
