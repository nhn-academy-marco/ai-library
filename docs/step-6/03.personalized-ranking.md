# Phase 3: 개인화 검색 결과 재정렬

## 학습 개요

사용자 선호도 벡터를 활용하여 **검색 결과를 개인화된 순위로 재정렬**하는 방법을 학습합니다. 기존 RRF(Reciprocal Rank Fusion) 점수와 선호도 유사도를 조합하여, 사용자가 더 관심 있을 만한 도서를 상위에 노출합니다.

## 학습 목표

1. **재정렬(Reranking) 개념 이해**
   - 1단계: 기존 검색 결과 획득
   - 2단계: 선호도 유사도 계산
   - 3단계: 점수 조합 및 재정렬

2. **점수 조합 공식 설계**
   - RRF 점수와 유사도의 가중치 합
   - 가중치 파라미터(0.3)의 역할과 조절
   - 기존 검색 결과 존중 vs 개인화 강화

3. **Telegram Bot 연동**
   - 검색 결과에 개인화 적용 여부 표시
   - 개인화 안내 메시지

## 1. 재정렬(Reranking) 개요

### 1.1 왜 재정렬이 필요한가?

**문제:** 기존 검색은 모든 사용자에게 같은 결과를 반환

```
검색: "자바"
사용자 A (웹 개발자):  → [일반 자바 도서들]  ← 스프링 관련 도서가 없음
사용자 B (백엔드 개발): → [일반 자바 도서들]  ← 알고리즘 관련 도서가 없음
```

**해결:** 개인화된 재정렬

```
검색: "자바"
사용자 A (웹 개발자):
  1. 스프링 부트 입문        ← 개인화로 상위 노출
  2. 자바 웹 프레임워크     ← 개인화로 상위 노출
  3. Effective Java         ← 기존 검색 결과

사용자 B (백엔드 개발):
  1. 자바 성능 튜닝         ← 개인화로 상위 노출
  2. 알고리즘 with 자바     ← 개인화로 상위 노출
  3. Effective Java         ← 기존 검색 결과
```

### 1.2 2단계 검색 아키텍처

```
[1단계: 기존 검색]
    ↓
[HybridSearchStrategy]
    ├─ Keyword Search
    └─ Vector Search
    ↓
[RRF 병합]
    └─ 검색 결과 1~N위 (일반 검색)
    ↓
[2단계: 개인화 재정렬]
    ↓
[PersonalizationService]
    ├─ 사용자 선호도 벡터 조회 (캐시)
    ├─ 각 도서별 유사도 계산
    └─ 최종 점수 = RRF + (유사도 × 0.3)
    ↓
[재정렬된 결과 1~N위] (개인화 적용)
```

**장점:**
- 기존 검색 결과를 완전히 무시하지 않음
- 개인화 효과를 점진적으로 반영
- 가중치 조절로 개인화 강도 조절 가능

## 2. 점수 조합 공식

### 2.1 수학적 정의

```
최종 점수 = RRF 점수 + (코사인 유사도 × α)

α (알파): 개인화 가중치 (0.0 ~ 1.0)
  - 0.0: 개인화 없음 (기존 검색만)
  - 0.3: 약한 개인화 (기존 검색 존중)
  - 0.5: 중간 개인화
  - 1.0: 강한 개인화 (선호도 위주)
```

### 2.2 계산 예시

**시나리오:** 사용자는 "웹 개발"을 좋아하고, 검색어는 "자바"

```
도서 A (스프링 부트 입문):
  RRF 점수: 0.025
  유사도:   0.85  (선호도와 매우 유사)
  최종:    0.025 + (0.85 × 0.3) = 0.025 + 0.255 = 0.280

도서 B (Effective Java):
  RRF 점수: 0.035  (검색어와 더 관련성 높음)
  유사도:   0.40  (선호도와 덜 유사)
  최종:    0.035 + (0.40 × 0.3) = 0.035 + 0.120 = 0.155

결과:
  Before: B(0.035) > A(0.025)  → Effective Java가 1위
  After:  A(0.280) > B(0.155)  → 스프링 부트가 1위 (개인화됨)
```

### 2.3 가중치 α의 역할

**α = 0.0 (개인화 없음)**
```
검색 결과: 기존 검색 그대로
장점: 검색어 관련성이 가장 높음
단점: 개인화 효과 없음
```

**α = 0.3 (약한 개인화) - 추천**
```
검색 결과: 기존 검색 존중 + 약간의 개인화
장점: 검색어 관련성 유지 + 개인화 효과
단점: 개인화 효과가 약할 수 있음
```

**α = 0.5 (중간 개인화)**
```
검색 결과: 검색어와 개인화 균형
장점: 개인화 효과가 명확함
단점: 검색어와 관련 없는 도서 노출 가능
```

**α = 1.0 (강한 개인화)**
```
검색 결과: 선호도 위주 (검색어 무시 가능)
장점: 개인화 효과 최대
단점: 검색어와 관련 없는 도서 노출 위험
```

## 3. 구현

### 3.1 PersonalizationService 확장

```java
@Service
@Slf4j
public class PersonalizationService {

    private static final double PERSONALIZATION_WEIGHT = 0.3;

    /**
     * 검색 결과를 개인화된 순서로 재정렬합니다.
     *
     * @param results 기존 검색 결과 (RRF 점수 포함)
     * @param chatId 사용자 chatId
     * @return 개인화된 검색 결과
     */
    public List<BookSearchResponse> personalizedSearch(
        List<BookSearchResponse> results,
        Long chatId
    ) {
        // [콜드 스타트 체크] 선호도 벡터가 없으면 그대로 반환
        float[] userPreferenceVector = calculateUserPreferenceVector(chatId);
        if (userPreferenceVector == null) {
            log.debug("No user preference vector for chatId: {}, skipping personalization",
                PrivacyUtil.maskChatId(chatId));
            return results;
        }

        log.info("Applying personalization for chatId: {}, resultCount: {}",
            PrivacyUtil.maskChatId(chatId), results.size());

        // [각 도서별 최종 점수 계산]
        List<BookSearchResponse> personalizedResults = results.stream()
            .map(result -> {
                float[] bookEmbedding = result.getEmbedding();
                double similarity = VectorUtils.cosineSimilarity(
                    userPreferenceVector,
                    bookEmbedding
                );

                double rrfScore = result.getScore();
                double finalScore = rrfScore + (similarity * PERSONALIZATION_WEIGHT);

                log.debug("Book: {}, RRF={}, Similarity={}, Final={}",
                    result.getTitle(), rrfScore, similarity, finalScore);

                // 점수 업데이트 (임시로 필드에 저장)
                result.setScore(finalScore);
                result.setPersonalizationScore(similarity);

                return result;
            })
            .sorted((r1, r2) -> Double.compare(r2.getScore(), r1.getScore()))  // 내림차순
            .collect(Collectors.toList());

        return personalizedResults;
    }
}
```

### 3.3 BookSearchService 연동

```java
@Service
public class BookSearchService {

    private final HybridSearchStrategy hybridSearchStrategy;
    private final PersonalizationService personalizationService;

    /**
     * 도서를 검색하고 개인화를 적용합니다.
     */
    public List<BookSearchResponse> searchBooks(String query, Long chatId) {
        log.info("Searching books: query={}, chatId={}", query,
            PrivacyUtil.maskChatId(chatId));

        // [1단계] 기존 검색 (HybridSearchStrategy)
        List<BookSearchResponse> results = hybridSearchStrategy.search(query, topK);

        // [2단계] 개인화 재정렬
        List<BookSearchResponse> personalizedResults =
            personalizationService.personalizedSearch(results, chatId);

        return personalizedResults;
    }
}
```

### 3.4 Telegram Bot 수정

```java
@Component
public class LibraryTelegramBot extends TelegramLongPollingBot {

    private final BookSearchService bookSearchService;

    private void handleSearch(SendMessage message, String query) {
        Long chatId = message.getChatId();

        // 검색 수행 (개인화 포함)
        List<BookSearchResponse> results = bookSearchService.searchBooks(query, chatId);

        // 개인화 여부 확인
        boolean isPersonalized = results.stream()
            .anyMatch(r -> r.getPersonalizationScore() != null);

        // 결과 메시지 구성
        StringBuilder response = new StringBuilder();
        response.append("📚 \"").append(query).append("\" 검색 결과\n\n");

        if (isPersonalized) {
            response.append("✨ *개인화된 추천*이 적용되었습니다!\n");
            response.append("사용자님의 취향을 분석하여 맞춤 결과를 보여드립니다.\n\n");
        }

        response.append(String.format("검색된 도서 (%d개)\n\n", results.size()));

        for (int i = 0; i < results.size(); i++) {
            BookSearchResponse book = results.get(i);
            response.append(String.format("%d. %s\n", i + 1, book.getTitle()));
            response.append(String.format("   📖 %s\n", book.getAuthor()));
            response.append(String.format("   🎯 유사도: %.2f%%\n", book.getScore() * 100));

            // 개인화 점수 표시
            if (book.getPersonalizationScore() != null) {
                response.append(String.format("   💝 선호도: %.2f%%\n",
                    book.getPersonalizationScore() * 100));
            }

            response.append("\n");
        }

        // 전송
        SendMessage sendResponse = SendMessage.builder()
            .chatId(chatId)
            .text(response.toString())
            .parseMode(ParseMode.MARKDOWN)
            .build();
        execute(sendResponse);
    }
}
```

```java
@SpringBootTest
class PersonalizationServiceTest {

    @Autowired
    private PersonalizationService personalizationService;

    @Test
    void testPersonalizedSearch_WithPreference() {
        // Given: 사용자 선호도 벡터 (웹 개발 선호)
        Long chatId = 12345L;
        List<BookSearchResponse> results = createMockResults();

        // When: 개인화 검색
        List<BookSearchResponse> personalized =
            personalizationService.personalizedSearch(results, chatId);

        // Then: 순서 변경 확인
        assertEquals("스프링 부트入门", personalized.get(0).getTitle());
        assertEquals("Effective Java", personalized.get(1).getTitle());
    }

    @Test
    void testPersonalizedSearch_ColdStart() {
        // Given: 피드백 없는 사용자
        Long chatId = 99999L;
        List<BookSearchResponse> results = createMockResults();

        // When: 개인화 검색
        List<BookSearchResponse> personalized =
            personalizationService.personalizedSearch(results, chatId);

        // Then: 순서 변경 없음
        assertEquals(results, personalized);
    }

    private List<BookSearchResponse> createMockResults() {
        return List.of(
            BookSearchResponse.builder()
                .id(1L)
                .title("Effective Java")
                .score(0.035)
                .embedding(createJavaEmbedding())  // 자바 일반
                .build(),
            BookSearchResponse.builder()
                .id(2L)
                .title("스프링 부트入门")
                .score(0.025)
                .embedding(createSpringEmbedding())  // 웹 개발
                .build()
        );
    }
}
```

## 6. 모니터링

### 6.1 개인화 효과 측정

```java
@Component
public class PersonalizationMetrics {

    private final MeterRegistry meterRegistry;

    public void recordPersonalization(Long chatId, boolean applied) {
        // 개인화 적용률 측정
        Counter.builder("personalization.applied")
            .tag("applied", String.valueOf(applied))
            .register(meterRegistry)
            .increment();
    }

    public void recordPreferenceScore(Long chatId, double score) {
        // 선호도 점수 분포 측정
        Gauge.builder("personalization.preference_score", score, Double::doubleValue)
            .register(meterRegistry);
    }
}
```
