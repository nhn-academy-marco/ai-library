# Phase 3: 개인화 검색 결과 재정렬

## 학습 개요

사용자 선호도 벡터를 활용하여 검색 결과를 개인화된 순위로 재정렬하는 방법을 학습합니다. 기존 RRF(Reciprocal Rank Fusion) 점수와 선호도 유사도를 조합하여, 사용자가 더 관심 있을 만한 도서를 상위에 노출합니다.

## 학습 목표

1. **재정렬(Reranking) 개념 이해**
   - 1단계: 기존 검색 결과 획득
   - 2단계: 선호도 유사도 계산
   - 3단계: 점수 조합 및 재정렬

2. **점수 조합 공식 설계**
   - RRF 점수와 유사도의 가중치 합
   - 가중치 파라미터(0.3)의 역할과 조절
   - 기존 검색 결과 존중 vs 개인화 강화

3. **Telegram Bot 연동**
   - 검색 결과에 개인화 적용 여부 표시
   - 개인화 안내 메시지

---

## 1. 재정렬(Reranking) 개요

### 1.1 왜 재정렬이 필요한가?

**문제:** 기존 검색은 모든 사용자에게 같은 결과를 반환

```
검색: "자바"
사용자 A (웹 개발자):  → [일반 자바 도서들]  ← 스프링 관련 도서가 없음
사용자 B (백엔드 개발): → [일반 자바 도서들]  ← 알고리즘 관련 도서가 없음
```

**해결:** 개인화된 재정렬

```
검색: "자바"
사용자 A (웹 개발자):
  1. 스프링 부트 입문        ← 개인화로 상위 노출
  2. 자바 웹 프레임워크     ← 개인화로 상위 노출
  3. Effective Java         ← 기존 검색 결과

사용자 B (백엔드 개발):
  1. 자바 성능 튜닝         ← 개인화로 상위 노출
  2. 알고리즘 with 자바     ← 개인화로 상위 노출
  3. Effective Java         ← 기존 검색 결과
```

### 1.2 2단계 검색 아키텍처

```
[1단계: 기존 검색]
    ↓
[HybridSearchStrategy]
    ├─ Keyword Search
    └─ Vector Search
    ↓
[RRF 병합]
    └─ 검색 결과 1~N위 (일반 검색)
    ↓
[2단계: 개인화 재정렬]
    ↓
[PersonalizationService]
    ├─ 사용자 선호도 벡터 조회 (캐시)
    ├─ 각 도서별 유사도 계산
    └─ 최종 점수 = RRF + (유사도 × 0.3)
    ↓
[재정렬된 결과 1~N위] (개인화 적용)
```

**장점:**
- 기존 검색 결과를 완전히 무시하지 않음
- 개인화 효과를 점진적으로 반영
- 가중치 조절로 개인화 강도 조절 가능

## 2. 점수 조합 공식

### 2.1 수학적 정의

```
최종 점수 = RRF 점수 + (코사인 유사도 × α)

α (알파): 개인화 가중치 (0.0 ~ 1.0)
  - 0.0: 개인화 없음 (기존 검색만)
  - 0.3: 약한 개인화 (기존 검색 존중)
  - 0.5: 중간 개인화
  - 1.0: 강한 개인화 (선호도 위주)
```

### 2.2 계산 예시

**시나리오:** 사용자는 "웹 개발"을 좋아하고, 검색어는 "자바"

```
도서 A (스프링 부트 입문):
  RRF 점수: 0.025
  유사도:   0.85  (선호도와 매우 유사)
  최종:    0.025 + (0.85 × 0.3) = 0.025 + 0.255 = 0.280

도서 B (Effective Java):
  RRF 점수: 0.035  (검색어와 더 관련성 높음)
  유사도:   0.40  (선호도와 덜 유사)
  최종:    0.035 + (0.40 × 0.3) = 0.035 + 0.120 = 0.155

결과:
  Before: B(0.035) > A(0.025)  → Effective Java가 1위
  After:  A(0.280) > B(0.155)  → 스프링 부트가 1위 (개인화됨)
```

### 2.3 가중치 α의 역할

**α = 0.0 (개인화 없음)**
```
검색 결과: 기존 검색 그대로
장점: 검색어 관련성이 가장 높음
단점: 개인화 효과 없음
```

**α = 0.3 (약한 개인화) - 추천**
```
검색 결과: 기존 검색 존중 + 약간의 개인화
장점: 검색어 관련성 유지 + 개인화 효과
단점: 개인화 효과가 약할 수 있음
```

**α = 0.5 (중간 개인화)**
```
검색 결과: 검색어와 개인화 균형
장점: 개인화 효과가 명확함
단점: 검색어와 관련 없는 도서 노출 가능
```

**α = 1.0 (강한 개인화)**
```
검색 결과: 선호도 위주 (검색어 무시 가능)
장점: 개인화 효과 최대
단점: 검색어와 관련 없는 도서 노출 위험
```

## 3. 구현

### 3.1 PersonalizationService 확장

`PersonalizationServiceImpl`에 재정렬 메서드를 추가합니다. 가중치(0.3)는 `app.personalization.weight` 설정으로 조절합니다.

```java
@Slf4j
@Service
@RequiredArgsConstructor
public class PersonalizationServiceImpl implements PersonalizationService {

    @Value("${app.personalization.weight:0.3}")
    private double personalizationWeight;

    private final BookRepository bookRepository;

    /**
     * 검색 결과를 개인화된 순서로 재정렬합니다.
     *
     * @param results 기존 검색 결과 (RRF 점수 포함)
     * @param chatId 사용자 chatId
     * @return 개인화된 검색 결과
     */
    @Override
    public List<BookSearchResponse> personalizedSearch(
        List<BookSearchResponse> results,
        Long chatId
    ) {
        // [콜드 스타트 체크] 선호도 벡터가 없으면 그대로 반환
        float[] preferenceVector = calculateUserPreferenceVector(chatId);
        if (preferenceVector == null) {
            log.debug("[PERSONALIZATION] No preference vector for chatId: {}, skipping personalization", chatId);
            return results;
        }

        log.info("[PERSONALIZATION] Applying personalization for chatId: {}", chatId);

        // [N+1 방지] 검색 결과 도서들의 임베딩을 한 번에 조회
        List<Long> bookIds = results.stream()
            .map(BookSearchResponse::getId)
            .collect(Collectors.toList());
        List<float[]> embeddings = bookRepository.findEmbeddingsByIds(bookIds);

        Map<Long, float[]> embeddingMap = new HashMap<>();
        for (int i = 0; i < bookIds.size(); i++) {
            if (i < embeddings.size()) {
                embeddingMap.put(bookIds.get(i), embeddings.get(i));
            }
        }

        // [각 도서별 최종 점수 계산]
        return results.stream()
            .map(response -> {
                float[] bookEmbedding = embeddingMap.get(response.getId());
                if (bookEmbedding == null) {
                    return response;
                }

                double similarity = VectorUtils.calculateCosineSimilarity(preferenceVector, bookEmbedding);

                double rrfScore = response.getRrfScore() != null ? response.getRrfScore() : 0.0;
                double finalScore = rrfScore + (similarity * personalizationWeight);

                // 점수 업데이트 (similarity 필드에 개인화 유사도, rrfScore 필드에 최종 점수 저장)
                response.setSimilarity(similarity);
                response.setRrfScore(finalScore);

                log.debug("[PERSONALIZATION] Book: {}, Similarity: {}, Final Score: {}",
                    response.getTitle(), similarity, finalScore);

                return response;
            })
            .sorted((a, b) -> {
                double scoreA = a.getRrfScore() != null ? a.getRrfScore() : 0.0;
                double scoreB = b.getRrfScore() != null ? b.getRrfScore() : 0.0;
                return Double.compare(scoreB, scoreA);  // 내림차순
            })
            .collect(Collectors.toList());
    }
}
```

> **참고:** `findEmbeddingsByIds()`는 `IN` 쿼리라 반환 순서가 `bookIds` 순서와 같다고 보장되지 않고, 임베딩이 없는 도서는 결과에서 빠집니다. 인덱스로 매핑하는 위 방식은 단순화한 것이므로, 정확하게 하려면 도서 ID와 임베딩을 함께 조회해 매핑하는 것이 안전합니다.

### 3.3 BookSearchService 연동

```java
@Service
@RequiredArgsConstructor
public class BookSearchService {

    private final PersonalizationService personalizationService;

    /**
     * 도서를 검색하고 개인화를 적용합니다.
     */
    @Transactional(readOnly = true)
    public BookSearchResult searchBooks(Pageable pageable, BookSearchRequest request, Long chatId) {
        log.info("Searching books with personalization for chatId: {}", chatId);

        // [1단계] 기존 검색 (검색 전략 + RRF)
        BookSearchResult result = searchBooks(pageable, request);

        // [2단계] 개인화 재정렬
        List<BookSearchResponse> personalizedBooks = personalizationService.personalizedSearch(
            result.getBooks().getContent(),
            chatId
        );

        // [3단계] 결과 재구성
        return new BookSearchResult(
            new PageImpl<>(personalizedBooks, pageable, result.getBooks().getTotalElements()),
            result.getAiResponse()
        );
    }
}
```

```java
@Component
public class LibraryTelegramBot extends TelegramLongPollingBot {

    private final BookSearchService bookSearchService;

    private void handleSearch(Update update, String keyword) {
        Long chatId = update.getMessage().getChatId();

        // 검색 수행 (개인화 포함)
        Pageable pageable = PageRequest.of(0, 5);
        BookSearchRequest request = new BookSearchRequest(keyword, null, SearchType.RAG, null, false);
        BookSearchResult result = bookSearchService.searchBooks(pageable, request, chatId);

        // 결과 전송 (헤더 + 도서별 메시지)
        sendSearchResult(chatId, keyword, result);
    }

    private void sendBookWithScore(Long chatId, String keyword, int index, BookSearchResponse book) {
        StringBuilder bookInfo = new StringBuilder();
        bookInfo.append(index).append(". ").append(book.getTitle()).append("\n");
        bookInfo.append("📖 ").append(book.getAuthorName()).append("\n");

        // 개인화 적용 시: similarity = 선호도 유사도, rrfScore = 최종 점수
        if (book.getSimilarity() != null && book.getSimilarity() > 0) {
            bookInfo.append(String.format("🎯 유사도: %.2f%%\n", book.getSimilarity() * 100));
        }
        if (book.getRrfScore() != null && book.getRrfScore() > 0) {
            bookInfo.append(String.format("📊 RRF 점수: %.2f\n", book.getRrfScore()));
        }

        // ... 이미지 또는 텍스트 + 피드백 키보드 전송
    }
}
```

### 5.1 단위 테스트

```java
@ExtendWith(MockitoExtension.class)
class PersonalizationServiceImplTest {

    @Mock
    private BookRepository bookRepository;

    @Mock
    private SearchFeedbackRepository feedbackRepository;

    @InjectMocks
    private PersonalizationServiceImpl personalizationService;

    private static final Long CHAT_ID = 12345L;

    @BeforeEach
    void setUp() {
        // @Value 필드는 직접 설정
        ReflectionTestUtils.setField(personalizationService, "minFeedbackCount", 3);
        ReflectionTestUtils.setField(personalizationService, "maxFeedbackCount", 20);
        ReflectionTestUtils.setField(personalizationService, "personalizationWeight", 0.3);
    }

    @Test
    void testPersonalizedSearch_WithPreference() {
        // Given: 웹 개발 도서 3권에 GOOD 피드백 (선호도 벡터 ≈ [0, 1])
        when(feedbackRepository.findByChatIdOrderByCreatedAtDesc(CHAT_ID))
            .thenReturn(List.of(
                SearchFeedback.of(CHAT_ID, "웹", 11L, FeedbackType.GOOD),
                SearchFeedback.of(CHAT_ID, "웹", 12L, FeedbackType.GOOD),
                SearchFeedback.of(CHAT_ID, "웹", 13L, FeedbackType.GOOD)
            ));
        when(bookRepository.findEmbeddingsByIds(anyList()))
            .thenReturn(List.of(new float[]{0f, 1f}, new float[]{0f, 1f}, new float[]{0f, 1f}))  // 선호 도서
            .thenReturn(List.of(new float[]{1f, 0f}, new float[]{0f, 1f}));                    // 검색 결과
        List<BookSearchResponse> results = createMockResults();

        // When: 개인화 검색
        List<BookSearchResponse> personalized =
            personalizationService.personalizedSearch(results, CHAT_ID);

        // Then: 순서 변경 확인
        assertThat(personalized.get(0).getTitle()).isEqualTo("스프링 부트 입문");
        assertThat(personalized.get(1).getTitle()).isEqualTo("Effective Java");
    }

    @Test
    void testPersonalizedSearch_ColdStart() {
        // Given: 피드백 없는 사용자
        when(feedbackRepository.findByChatIdOrderByCreatedAtDesc(CHAT_ID))
            .thenReturn(new ArrayList<>());
        List<BookSearchResponse> results = createMockResults();

        // When: 개인화 검색
        List<BookSearchResponse> personalized =
            personalizationService.personalizedSearch(results, CHAT_ID);

        // Then: 순서 변경 없음
        assertThat(personalized).isEqualTo(results);
    }

    private List<BookSearchResponse> createMockResults() {
        return List.of(
            // (id, isbn, title, volumeTitle, authorName, publisherName, price,
            //  editionPublishDate, imageUrl, bookContent, similarity, rrfScore)
            new BookSearchResponse(1L, null, "Effective Java", null, null, null,
                null, null, null, null, null, 0.035),   // 자바 일반
            new BookSearchResponse(2L, null, "스프링 부트 입문", null, null, null,
                null, null, null, null, null, 0.025)    // 웹 개발
        );
    }
}
```

## 학습 요약

### 핵심 개념

1. **재정렬(Reranking)**
   - 기존 검색 결과에 개인화 적용
   - 2단계: 검색 → 재정렬
   - 사용자 경험 개선

2. **점수 조합 공식**
   - `최종 점수 = RRF + (유사도 × 0.3)`
   - 가중치 0.3으로 기존 검색 존중
   - α 조절로 개인화 강도 조절

3. **사용자 경험**
   - 개인화 여부 UI 표시
   - 선호도 점수 노출
