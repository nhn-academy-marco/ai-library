## 트러블슈팅

### 1. Inline Keyboard가 표시되지 않음

**원인:** `replyMarkup` 설정 누락
**해결:** `SendMessage.builder().replyMarkup(keyboard).build()` 확인

### 2. Callback 데이터 파싱 오류

**원인:** 특수 문자(`:`) 처리 미흡
**해결:** URL 인코딩/디코딩 사용

### 3. JPA Entity 생성 오류

**원인:** 기본 생성자 누락
**해결:** `@NoArgsConstructor(access = AccessLevel.PROTECTED)` 추가

### 4. 트랜잭션 롤백 문제

**원인:** `@Transactional` 누락
**해결:** Service 메서드에 `@Transactional` 추가

### 피드백 수집의 핵심

```
사용자 → 검색 → 결과 확인 → 피드백(👍/👎) → 데이터 저장
   ↑                                              ↓
   └──────── 통계 분석, 품질 모니터링 ←──────────┘
```

이 피드백 시스템은 다음과 같은 기능을 제공합니다.

1. **데이터 수집**: 사용자 피드백을 데이터베이스에 저장
2. **통계 분석**: 검색어별/도서별 피드백 통계 제공
3. **품질 모니터링**: 관리자 API를 통해 피드백 현황 파악
